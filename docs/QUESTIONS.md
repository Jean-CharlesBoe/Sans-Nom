## Répondues

- **Q 1. Appareils** → chacun son téléphone. Pas de mot de passe. L'utilisateur veut que les données ne soient **pas perdues si le navigateur est nettoyé** (propose SQLite) → suite en Q 1 bis / D5.
- **Q 2. Règles v0** → les caracs évoluent avec l'expérience. La règle des 40 points n'est **pas gardée** (ni pour les joueurs, ni pour les créatures). Plafond 1–12 supprimé.
- **Q 3. Case sous la carac** → avantages : N avantages = N relances du jet. Les désavantages sont gérés par le MJ (voir Q 26). Le trait au-dessus du cercle = nom de la carac.
- **Q 4. Bonus / malus** → les boutons + / − éditent simplement la valeur de la carac (à afficher tout le temps ou seulement en mode édition → Q 25). Il faut des **bonus temporaires** (+N sur une carac, qu'un perso se donne ou reçoit d'un autre) → Q 24.
- **Q 5. Ressources** → maximums saisis à la main, jamais calculés. **PP = points d'action** (créatures).
- **Q 6. Onglets** → un onglet unique « Invocations » (animaux totem, invocations, animaux de compagnie) : liste → tap = fiche → bouton + pour ajouter. Pas de limite de nombre.
- **Q 7. Créatures** → mêmes 8 caracs. Ressources : Vie et PP pour l'instant (pourra dépendre du type plus tard). Pas de règle des 40 points.
- **Q 8. Équipement** → pas de schéma du corps.
- **Q 9. Inventaire** → texte libre, pas d'argent ni de poids.
- **Q 10. Compétences** → coût toujours en mana (PP pour les créatures). Pas de champ Dés.
- **Q 11. Fonctions v0** → Lore, Histoire, Dessins, portrait, impression, mémos : **non conservés**.
- **Q 12. Lanceur de dés** → non.
- **Q 13. Hébergement** → l'utilisateur a un compte GitHub.
- **Q 14. Google Sheet** → fichier `Eloy.xlsx` fourni le 2026-10-08, analysé dans ANALYSE_FICHE_ELOY.md.
- **Q 15. Style** → mode sombre souhaité.
- **Q 16. XP** → un compteur d'XP à dépenser avec un rappel de la règle (1 XP = +1 carac ou +2 au max d'une ressource).
- **Q 17. Race / pratiques** → champs séparés (détails en Q 23).
- **Q 18. Champs en plus** → garder **Titre** (nom obtenu en jeu) et **Régénération** par ressource (évolue avec le temps). Les animaux de compagnie ont leur propre fiche, comme les invocations.
- **Q 19. Âme** → ressource cur/max (max 100 chez Eloy), qui peut diminuer.
- **Q 20. Dépassement du max** → interdit : une ressource ne dépasse jamais son max (130/110 chez Eloy était une erreur).
- **Q 21. Notes / relations** → non.
- **Q 1 bis. Stockage** → option **B** : app Android (Capacitor) + SQLite (D5).
- **Q 22. Téléphones** → tous sous Android.
- **Q 23. Races / pratiques** → liste de races **fermée** (celle de la v0). Un **Nain ne peut pas avoir de mana**. Pratiques immatérielles : **liste** (1 au départ, 2 pour Eloy aujourd'hui, potentiellement plus), sans limite.
- **Q 24. Bonus temporaires** → pas de durée, suppression manuelle.
- **Q 25. Mode édition** → validé (mode jeu par défaut, crayon pour éditer).
- **Q 26. Désavantages** → la case peut afficher un désavantage (valeur négative).
- **Q 27. Compétences** → pas de catégories ; compétence de race = compétence ordinaire.
- **Q 28. Dépôt** → public, nommé « Sans Nom » (nom du JDR) → `Sans-Nom` sur GitHub (pas d'espace possible).
- **Q 29. Chromebook** → non, téléphones Android uniquement.
- **Q 30. Outils** → Node.js LTS et Android Studio installés le 2026-10-08.
